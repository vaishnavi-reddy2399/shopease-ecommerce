🌟 About the Project

ShopEase is a beginner-friendly e-commerce website designed to provide a simple and convenient online shopping experience.

Users can explore products, search for their favourite items, filter products by category, add products to a shopping cart, and calculate the total cost.

The project demonstrates fundamental frontend development concepts, responsive UI design, and JavaScript-based interactivity.

🎯 Project Objectives

- Build an attractive and user-friendly shopping interface.
- Develop a responsive website for different screen sizes.
- Understand HTML page structure and CSS styling.
- Implement dynamic product rendering using JavaScript.
- Practise search, filtering, and shopping cart functionality.

✨ Key Features

Feature| Description
🏠 Modern Homepage| Attractive banner and shopping layout
🛒 Product Catalog| Displays products with names, categories, and prices
🔎 Product Search| Finds products by name
🗂️ Category Filter| Filters products by category
➕ Add to Cart| Adds products to the shopping cart
➖ Remove Items| Removes products from the cart
🧮 Price Calculation| Updates item quantities and total price
📱 Responsive Design| Adapts to desktop, tablet, and mobile screens
💬 Checkout Demo| Demonstrates a basic checkout interaction

🛠️ Technologies Used

- HTML5 — structures the webpage and its content.
- CSS3 — provides styling, product cards, layouts, and responsive media queries.
- JavaScript — implements search, category filtering, cart management, and price calculations.
- Visual Studio Code — used for development.
- GitHub — used for source code hosting and version control.

🚀 Getting Started

Follow these steps to run the project on your computer.

1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/shopease-ecommerce.git

Replace "YOUR-USERNAME" with your GitHub username.

2. Open the Project

cd shopease-ecommerce

Open the folder in Visual Studio Code.

3. Run the Website

Open "index.html" in your browser, or use the Live Server extension in VS Code.

No additional packages are required for the current frontend version.

⚠️ Current Limitations

This is a frontend demonstration project. Products are stored in JavaScript, cart information is held in memory, and checkout is simulated.

A backend, database, and payment service would be needed for persistent orders and real online transactions.
