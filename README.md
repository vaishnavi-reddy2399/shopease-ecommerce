ShopEase – Responsive E-Commerce Website

About the Project

ShopEase is a beginner-friendly, responsive e-commerce website developed using HTML, CSS, and JavaScript. It provides a simple online shopping experience where users can browse products, search for items, filter products by category, and manage a shopping cart.

Objectives

- To create a user-friendly online shopping interface.
- To learn frontend web development.
- To implement interactive features using JavaScript.
- To create a responsive layout for mobile, tablet, and desktop screens.

Technologies Used

- HTML5: Creates the structure of the website.
- CSS3: Provides styling, layouts, and responsive design.
- JavaScript: Handles product search, category filtering, cart operations, and price calculations.

Features

- Modern homepage and promotional banner.
- Product cards with names, categories, and prices.
- Product search functionality.
- Category-based product filtering.
- Add-to-cart functionality.
- Remove products from the cart.
- Automatic cart quantity and total price calculation.
- Responsive design for different screen sizes.
- Demo checkout message.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.

Future Enhancements

- User registration and login.
- Database integration for products and orders.
- Wishlist functionality.
- Product reviews and ratings.
- Backend order management.
- Secure payment gateway integration.

Limitations

This is a frontend demonstration project. Product data is stored in JavaScript, and checkout is simulated. It does not currently process real payments or save orders to a database.
